NovaGlow – AI-Powered Skincare/Makeup Product Showcase Website
Project Overview
This project involves designing and building a fully functional AI-powered skincare website using a no-code platform (Wix). The website showcases skincare products while integrating AI features such as content generation, chatbots, and design suggestions.
The project demonstrates how modern tools simplify website creation while enhancing personalization and user engagement — similar to real-world AI-first business solutions.
Features
1. Product Showcase
Clean grid layout with high-quality product images.
Sections for Featured Products, New Arrivals, and Bestsellers.
Product details include name, description, and price.
2. AI-Powered Features
Content Generation: AI-written product descriptions, blog posts, and homepage text.
Design Assistance: Wix AI provides layout, color, and font suggestions for a professional, visually appealing site.
3. Branding & UX
Modern, minimalist, and mobile-friendly design.
Soft pastel color palette reflecting skincare aesthetics.
About section detailing brand USP: natural, skin-friendly ingredients 
Platform: Wix (No-code website builder)
AI Tools: Wix AI (Content & Design)
Assets: Stock images, Canva mockups, AI-generated content
